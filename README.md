## 🏛️ &nbsp; Exemplaris Overview

> **ARCHIVUM** is a standalone, museum-grade portfolio repository catalogue designed for instant deployment on **GitHub & Vercel**. It eliminates the need for manual indexing by autonomously discovering, rendering live scaled thumbnails for, and exporting every single standalone HTML portfolio page stored anywhere across the root and nested directories of this repository.

## ✨ &nbsp; Architectural Capabilities

<details open>
<summary><b>🔍 1. Recursive Nested Directory Ingestion</b></summary>
<br/>

The catalogue hooks directly into the **GitHub Git Trees API** and relative directory crawlers to traverse your repository.
- Detects HTML documents nested at any depth (e.g. `portfolios/minimal/index.html`, `templates/creative/showcase.html`).
- Automatically preserves nested `index.html` pages while cleanly excluding only the root catalogue entry point.
- Extracts live page titles from the `<title>` tag and descriptions from `<meta name="description">`.

</details>

<details open>
<summary><b>🖼️ 2. Real-Time Scaled Viewport Thumbnails</b></summary>
<br/>

No static screenshot generation or third-party image APIs required.
- Each portfolio card hosts a sandboxed, hardware-accelerated `<iframe>` that scales the live HTML document to miniature viewport proportions.
- Automatically inserts a `<base href="./subfolder/">` tag into the document head to ensure all relative styles, fonts, and images render flawlessly.

</details>

<details open>
<summary><b>🌐 3. High-Contrast Three.js 3D Celestial Art Piece</b></summary>
<br/>

- **Solid Alabaster Core**: A high-density geodesic Icosahedron with procedural sinusoidal wave morphing.
- **24K Gold Nucleus**: Counter-rotating imperial gold stellation illuminated by an internal point-light core.
- **Kinetic Astrolabe Gimbals**: Triple concentric celestial meridian rings rotating on harmonic astronomical axes.
- **Interactive Mechanics**: Smooth touch & mouse drag-to-orbit with physics momentum decay and cursor tracking.

</details>

<details open>
<summary><b>📱 4. Multi-Device Sandbox Lightbox & One-Click Exporter</b></summary>
<br/>

- **Device Frame Switcher**: Inspect any portfolio inside responsive Desktop, Tablet (768px), and Mobile (380px) mock frames without leaving the catalogue.
- **Direct Downloader**: One-click direct blob downloading of any standalone portfolio file.
- **Instant Redirect**: Direct external launch tab for full production preview.

</details>

## 🚀 &nbsp; Quick Start & Adding Portfolios

```markdown
### Step 1: Add your HTML file
Drop any standalone `.html` page anywhere inside the repo (Root or any nested folder).

### Step 2: Push to GitHub
git add .
git commit -m "Add new portfolio opus"
git push origin main

### Step 3: Instant Live Indexing
Your Vercel deployment will immediately index the document, compute its size, generate its live thumbnail, and enable direct download capabilities!
```
